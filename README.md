# Esercizi Python 🐍

Serie di esercizi Python realizzati durante il mio percorso di apprendimento dopo la laurea in Informatica e Comunicazione Digitale.

## Esercizi

### Esercizio 1 - Saluto personalizzato
Programma che chiede nome e anno di nascita e calcola l'età.

### Esercizio 2 - Analisi lista numeri
Programma che chiede 5 numeri e restituisce massimo, minimo e media.

### Esercizio 3 - Calcolatrice
Calcolatrice base con le 4 operazioni e gestione della divisione per zero.

## Tecnologie
- Python 3.12
